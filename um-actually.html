Нашли ошибку? Вот как её исправить

Зачем эта страница

Данные на сайте собраны из rating.chgk.info API и дополнены вручную. Ошибки неизбежны: неправильное имя, не тот состав, пропущенный турнир. Если вы нашли неточность -- вы можете исправить её сами через GitHub.

Репозиторий: github.com/ImangulovA/chgk-worldwide

Быстрый путь: создать Issue

Если не хотите разбираться с кодом, просто опишите проблему:

  1. Перейдите в Issues → New Issue
  2. Напишите, что не так: страна, год, команда, что именно неправильно
  3. Если знаете правильный вариант -- укажите его

Это всё. Дальше разберёмся.

Полный путь: форк и Pull Request

1. Форкните репозиторий

Нажмите Fork на странице репозитория. Это создаст вашу копию.

2. Склонируйте к себе

git clone https://github.com/YOUR_USERNAME/chgk-worldwide.git
cd chgk-worldwide

3. Найдите нужный файл

Данные лежат в data/db/. Структура:

data/db/
├── players.json -- все игроки: {id: "Имя Фамилия"}
├── teams.json -- все команды: {id: {name, town}}
└── {country}/ -- папка страны (uk, ukraine, russia...)
    ├── meta.json -- информация о стране
    ├── tournaments.json -- список чемпионатов
    ├── display_names.json -- переопределения имён
    └── results/
        └── {tournament_id}.json -- результаты турнира

4. Типичные исправления

Исправить имя игрока:

Откройте data/db/players.json, найдите ID игрока, исправьте значение.

// было:
"12345": "Иван Иванов"
// стало:
"12345": "Іван Іванов"

Исправить название команды:

Откройте data/db/{country}/display_names.json и добавьте или исправьте запись:

{
  "teams": {
    "210": "Від Гвинта -- Брати по фазі"
  }
}

Исправить состав команды:

Откройте файл результатов data/db/{country}/results/{tournament_id}.json. Каждая запись выглядит так:

{
  "pos": 1.0,
  "team_id": 316,
  "score": 110,
  "roster": [30260, 23740, 22331, 16499, 10182]
}

roster -- это массив ID игроков из players.json. Добавьте или уберите ID.

ID игрока можно найти на rating.chgk.info -- он виден в URL страницы игрока.

Добавить турнир:

  1. Добавьте запись в data/db/{country}/tournaments.json
  2. Создайте файл результатов data/db/{country}/results/{id}.json
  3. Добавьте ID в data/tournament_classification.json в секцию "main"

5. Пересоберите сайт

python3 build_worldwide.py

Это обновит все HTML-файлы. Откройте index.html в браузере, проверьте результат.

6. Закоммитьте и отправьте PR

git add -A
git commit -m "Fix: исправлен состав Номер 6 в ЧУ 2017"
git push origin main

Затем на GitHub нажмите Contribute → Open Pull Request.

Формат файла результатов

Каждый results/{id}.json -- массив объектов:

[
  {
    "pos": 1.0,        // место (дробное при делёжке: 4.5)
    "team_id": 316,    // ID команды на rating.chgk.info
    "score": 110,      // количество взятых вопросов (0 если неизвестно)
    "roster": [        // ID игроков (пустой массив если неизвестен)
      30260,
      23740,
      22331
    ],
    "flags": [50]      // 50 = зачёт чемпионата страны (опционально)
  }
]
Важно: не меняйте структуру JSON. Не добавляйте запятую после последнего элемента массива.

Где брать ID

  • Игрок: rating.chgk.info/player/12345 -- число в URL
  • Команда: rating.chgk.info/teams/316 -- число в URL
  • Турнир: rating.chgk.info/tournament/3795 -- число в URL

Если турнира нет на rating.chgk.info, используйте виртуальный ID (90000+).
